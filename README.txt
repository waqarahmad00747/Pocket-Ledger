PocketLedger for Android (installable app, works offline)
=========================================================
Android only installs web apps from a secure https:// address, so upload this
folder once to a free host, then install from your phone.

EASIEST (2 minutes, free):
 1. On a computer open https://app.netlify.com/drop
 2. Drag this whole folder (PocketLedger-Android) onto the page.
 3. Netlify gives you an address like https://something.netlify.app
 4. On your Android phone open that address in Chrome.
 5. Tap the ⋮ menu > "Install app" (or "Add to Home screen").
 PocketLedger now has its own icon, opens full screen and works with no internet.

Your data stays on the phone only (never uploaded). The host only serves the app files.

BACKUP ON ANDROID (Save & Backup tab, "Phone safety"):
 - Share backup: sends the backup file to Google Drive, WhatsApp, email, etc.
 - Protected storage: stops Android clearing the app's data when space is low.
 - Automatic snapshots: the app keeps its last 10 copies and can restore any.
 Android Chrome cannot write silently into a chosen folder (browser limitation),
 so share a backup weekly; the app reminds you.

Files: index.html (the app), manifest.webmanifest, sw.js (offline), icons.
